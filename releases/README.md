# UCD VS FRST release inventory

This directory is the binary-package index for the versioned UCD VS FRST workbenches. The same research line is also browsable directly under `machines/`, `frst/`, `comparison/`, `ucd/`, `paper/`, and `results/`.

## Versioned release line

- `UCD_P0_FINITE_REALIZATION_TERMINALITY_v14_0.zip` — UCD finite-realization/terminality workbench.
- `UCD_VS_FRST_SELECTOR_ACTUALITY_v2_0.zip` — selector, actuality and continuum-envelope reduction.
- `UCD_VS_FRST_SOURCE_SELECTOR_TOURNAMENT_v3_0.zip` — source-selector tournament.
- `UCD_VS_FRST_NATIVE_ACTUALIZATION_GRAMMAR_v4_0.zip` — native actualization grammar audit.
- `UCD_VS_FRST_FINITE_SEPARATOR_BASIS_v5_0.zip` — finite separator basis theorem/workbench.
- v6 source-finiteness material is fully browsable under `machines/v6/`; its release-package status should be judged from the actual files visible in this directory rather than inferred from this index.

## Human-readable entry points

The main theory and comparison documents are under `paper/`. The frozen FRST source is under `frst/v1.0/`.

## Verification rule

A ZIP is considered published only when the binary file itself is visible in this Git tree. A local checksum or release name alone is not treated as publication. Machine `PASS` results mean the encoded mathematical checks reproduced; they are not empirical confirmation of UCD or FRST.
