# UCD VS FRST

Versioned research repository for the frozen **Finite Relational Selection Theory (FRST)** and **Unified Coherence Dynamics (UCD)** comparison program, theorem/countermodel machines, provenance firewalls and reproducible verdicts.

## Canonical UCD name

**UCD = Unified Coherence Dynamics.**

- **Unified** — one framework intended to connect the physical and mathematical layers.
- **Coherence** — preservation, organization and relational alignment of states/information.
- **Dynamics** — how those states and relations change, propagate, interact and produce observables.

This repository must not expand UCD as “Unified Codex Dynamics.” The canonical name used by the UCD core papers is **Unified Coherence Dynamics**.

## Non-merger rule

FRST and UCD stay distinct unless a later reviewed integration explicitly says otherwise. FRST v1.0 **assumes** finite actuality. UCD does not receive that assumption for free: its upstream finite-realization problem must be derived or remain open.

The common organizational hierarchy is

`mathematical possibility -> physical admissibility -> lawful dynamics -> actual realized history`.

The corresponding general data are `(P_phys, H, rho_0)` plus the mathematical carrier. A theorem about one layer is not silently promoted into another.

## Current mathematical fixed point

The current Root/P0 source grammar has an explicit infinite countermodel, so global primordial finiteness cannot be extracted from the old premises by more enumeration. Downstream H504/Q72 finiteness also cannot be pushed backward through the provenance firewall.

v5 proved that a finite complete separating witness basis is sufficient for finite capacity. v6 then proved the converse: if arbitrary predicates may be chosen, such a finite complete separator basis exists exactly when the realized set is finite. Thus `P0-FINSEP` is a useful operational characterization, not by itself the deeper explanation.

The highest-value source-dynamical route is therefore again:

`P0-F1: finite immediate lawful actualization`

plus

`P0-F2: no infinite physically realized strict differentiation chain`.

Together they imply a finite realized tree by Koenig's infinity lemma. Both source premises remain `NEW_THEOREM_REQUIRED`.
