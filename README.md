# UCD VS FRST

## Unified Coherence Dynamics compared with Finite Relational Selection Theory

This repository compares two relational approaches to fundamental reality.

**Unified Coherence Dynamics (UCD)** is the specific framework developed around coherence, registration, Q72, H504 and H-net structure. **Finite Relational Selection Theory (FRST)** was built independently as a more general mathematical ontology in which reality is modeled as one finite, constrained relational quantum system.

The central comparison is:

```text
all mathematical possibilities
        |
        v
physically admissible states
        |
        v
actual realized creation/history
```

In symbols: `Omega_realized subseteq Omega_physical subseteq Omega_mathematical`.

FRST supplies a generic architecture for that hierarchy. UCD asks the harder and more specific question: can the structures FRST initially assumes be **derived** from the UCD source law, and can that derivation force the specific Q72/H504/H-net architecture rather than merely permit it?

## Theories are kept distinct

FRST v1.0 assumes finite actuality: `0 < |V| = N < infinity`.

UCD does **not** receive that premise for free. The UCD finite-realization program is attempting to derive physical finiteness from upstream source principles. A result assumed by FRST is never silently counted as a UCD theorem.

A useful common organizing form is `(P_phys, H, rho_0)`: `P_phys` selects physically admissible states from the larger mathematical possibility space, `H` gives lawful dynamics, and `rho_0` or an equivalent actualization law identifies the realized state/history.

## Current mathematical fixed point

The current source grammar admits an explicit infinite countermodel, so completed creation by itself is not yet a mathematical proof of finite cardinality. The strongest current UCD-native route is:

1. **P0-F1:** finite immediate lawful actualization / finite branching.
2. **P0-F2:** no infinite physically realized strict differentiation chain / well-foundedness.

With finite roots, F1 + F2 imply a finite realized tree by Koenig's infinity lemma. That implication is closed mathematics; F1 and F2 themselves remain source theorems to derive.

The comparison machine line sharpened this further:

- **v2:** selector, actuality and continuum-envelope reduction.
- **v3:** finite alphabet + bounded arity gives finite branching; well-founded rank gives finite depth.
- **v4:** finite Q72/H504 labels do not by themselves prove global H-net finiteness.
- **v5:** a finite complete separating witness basis is sufficient for finite realized capacity.
- **v6:** the separator basis is an operational characterization of finiteness, not the deeper cause of it.

## Reproducibility

The `machines/` directory contains the actual theorem/countermodel programs and machine verdicts. A machine `PASS` means the encoded mathematical claim or countermodel check executed as intended. It is **not** by itself experimental confirmation that UCD or FRST describes nature.
