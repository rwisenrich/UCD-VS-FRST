# Papers and human-readable documents

This folder contains the main human-readable entry points for the UCD VS FRST program.

- **FRST v1.0 Frozen Theory** — the independent Finite Relational Selection Theory frozen before comparison with UCD. The canonical source is also preserved under `frst/v1.0/`.
- **FRST vs UCD Comparison Report v1.0** — the first direct comparison between FRST and **Unified Coherence Dynamics**, including the import firewall and the distinction between an FRST axiom and a UCD theorem obligation.

The executable theorem/countermodel machines are under `machines/`. The UCD finite-realization foundation work is under `ucd/` and the versioned release inventory is under `releases/`.

A machine PASS verifies the encoded mathematical claim or countermodel. It is not experimental confirmation that either theory describes nature.
