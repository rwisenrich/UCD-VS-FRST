# UCD P0 Finite Realization / Terminality v14.0

This is the UCD-native finite-realization branch that was built before the FRST comparison was allowed to import any finiteness premise.

## Question

Why does Unified Coherence Dynamics forbid an actually infinite realized address set?

## Exact logical result

Finished/completed creation by itself does **not** imply finite cardinality. A completed realized set can still be countably infinite, so completion cannot be used as a disguised finiteness axiom.

The finite-realization route is instead:

`finite roots + finite immediate actualization + no infinite realized strict branch -> finite realized tree`.

The last implication is closed mathematics by Koenig's infinity lemma.

## Remaining source obligations

- `P0-F1`: finite immediate lawful actualization / finite branching.
- `P0-F2`: no infinite physically realized strict differentiation chain / well-foundedness.

These are source-level physical/mathematical principles still to be derived inside UCD.

## Consequence if closed

If the realized UCD carrier is finite and addressing is persistent/injective, then the realized address set is finite. A finite physical H-net follows once its vertices are exactly the realized primitive registrations and its admissible link set is a finite relation on them.

This v14 result is deliberately fail-closed: it does not infer global finiteness from the finite Q72/H504 codebook and it does not treat the H504 spectral gap as an ontic creation-cost theorem.
